## 麻雀の基本

麻雀は牌（はい/パイ）を使ったテーブルゲームです。各プレイヤーは手牌を揃え、特定の組み合わせ（役）を完成させて「和了（ホーラ/あがり）」を目指します。

### 基本用語

| 用語 | 読み | 意味 |
|------|------|------|
| 和了 | ホーラ | 手牌を完成させて上がること |
| テンパイ | — | あと1枚で和了できる状態 |
| シャンテン | — | テンパイまでに必要な牌の入れ替え回数 |
| 門前（メンゼン） | もんぜん | 副露（ポン・チー・明槓）をしていない状態 |
| 面子（メンツ） | めんつ | 3枚1組の牌の組み合わせ |
| 雀頭（ジャントウ） | じゃんとう | 対子（同じ牌2枚）のこと。和了形で1組必要 |

## 牌の種類

### 数牌（シューパイ）— 3種類 × 9種 × 4枚 = 108枚

| 種類 | 読み | 牌 | 説明 |
|------|------|----|------|
| 萬子 | マンズ (man) | 一萬～九萬 | 漢数字が書かれた牌 |
| 筒子 | ピンズ (pin) | 一筒～九筒 | 丸い図柄の牌 |
| 索子 | ソーズ (sou) | 一索～九索 | 竹の図柄の牌 |

### 字牌（ツーパイ）— 7種 × 4枚 = 28枚

| 分類 | 牌 | 内部番号 |
|------|----|----------|
| 風牌（カゼハイ） | 東・南・西・北 | honor 1・2・3・4 |
| 三元牌（サンゲンパイ） | 白・發・中 | honor 5・6・7 |

### 合計: 136枚

### 特殊な分類

| 分類 | 対象の牌 |
|------|----------|
| 么九牌（ヤオチューハイ） | 各スーツの1と9 + 全ての字牌 |
| 老頭牌（ロウトウハイ） | 各スーツの1と9のみ（字牌を含まない） |
| 中張牌（チュンチャンパイ） | 各スーツの2～8 |

## ゲームの流れ

### 1. 配牌（ハイパイ）

各プレイヤーに **13枚** の牌を配ります。親（東家）は最初に1枚ツモして **14枚** からスタートします。

### 2. ツモ（自摸）

自分のターンに牌山から1枚引きます。手牌は一時的に14枚になります。

### 3. 打牌（ダハイ）

手牌から不要な1枚を捨てて13枚に戻します。捨てた牌は河（カワ）に並べられ、全プレイヤーから見えます。

### 4. 鳴き（副露）/ 和了の判定

他プレイヤーの捨て牌に対して、条件を満たせばポン・カン・ロンを宣言できます。

### 5. 流局

牌山の残りがなくなると流局（引き分け）となります。

#### 途中流局（特殊な流局条件）

通常の牌山枯渇による流局以外に、以下の条件で途中流局が発生する場合があります。

| 条件 | 読み | 説明 |
|------|------|------|
| 九種九牌 | キュウシュキュウハイ | 第一ツモ時に么九牌が9種以上ある場合、流局を宣言可能 |
| 四槓散了 | スーカンサンラ | 2人以上が合計4回の槓を行った場合に流局（1人の4槓は四槓子として続行） |

> ⚠️ **本ゲームでは途中流局は未実装です。**

#### 流局時のテンパイ料

流局時にテンパイしているプレイヤーとノーテンのプレイヤーの間で点数の授受が行われます。一般的な4人麻雀ではテンパイ者全体で3,000点を受け取りますが、2人麻雀ではテンパイ者が +3,000点 / ノーテン者が −3,000点 とするのが一般的です。

> 本ゲームではテンパイ料はオプション機能（デフォルト無効、金額は1,500点）です。

#### 流し満貫（ナガシマンガン）

流局時に、自分の捨て牌がすべて么九牌であり、かつ1枚も他家に鳴かれていない場合に成立する特殊な役です。満貫（8,000点）として扱われます。

> ⚠️ **本ゲームでは流し満貫は未実装です。**

### ターンの繰り返し

> ツモ → 打牌 → （相手の鳴き判定） → 相手のツモ → … の繰り返し

## 手牌の完成形（和了形）

和了（あがり）するには、14枚の手牌で以下のいずれかの形を完成させる必要があります。

### 基本形: 4面子 + 1雀頭

**面子**（3枚1組）を4つと、**雀頭**（同じ牌2枚）を1つ揃えます。

#### 面子の種類

| 名称 | 読み | 構成 | 例 |
|------|------|------|----|
| 順子 | シュンツ | 同じスーツの連続3枚 | 一萬・二萬・三萬 |
| 刻子 | コーツ | 同じ牌3枚 | 東・東・東 |
| 槓子 | カンツ | 同じ牌4枚（槓で成立） | 白・白・白・白 |

> **注意**: 順子は数牌のみ（字牌では作れない）。9→1のように循環しない。

#### 雀頭（対子）

同じ牌2枚の組み合わせ。例: 五筒・五筒

### 特殊形: 七対子（チートイツ）

異なる対子を **7組** 揃える形。門前（メンゼン）限定。

```
例: 一萬一萬 三筒三筒 七索七索 東東 白白 中中 五萬五萬
```

### 特殊形: 国士無双（コクシムソウ）

13種類の么九牌（1・9・東・南・西・北・白・發・中）を1枚ずつ + うち1種を2枚。門前限定。

```
例: 一萬 九萬 一筒 九筒 一索 九索 東 南 西 北 白 發 中 + 東（重複）
```

## 副露（フーロ）

他プレイヤーの捨て牌を利用して面子を作ることを **副露**（鳴き）といいます。副露すると門前（メンゼン）ではなくなり、一部の役が成立しなくなります。

### ポン（碰）

相手の捨て牌1枚 + 手牌の同じ牌2枚 → **刻子**（明刻）を作ります。

- どのプレイヤーの捨て牌からでもポン可能
- ポンした面子は公開され、以降手出しできない

### 槓（カン）の詳細は [槓（カン）](#槓カン) を参照

### チー（吃）

> **本ゲーム（2人麻雀）ではチーは不可**

通常の4人麻雀では、上家（左隣のプレイヤー）の捨て牌で順子を作れますが、2人麻雀では採用していません。

### 副露による影響

| 影響 | 説明 |
|------|------|
| 門前でなくなる | 立直不可、門前ツモ不可 |
| 翻数が下がる役がある | 混一色 3翻→2翻、清一色 6翻→5翻 など |
| 成立しなくなる役がある | 平和、一盃口、二盃口 など |

> **例外**: 暗槓は副露とみなさず、門前を維持します。

## 立直（リーチ）

### 宣言条件

1. **門前**であること（暗槓のみならOK）
2. **テンパイ**状態であること
3. 持ち点が **1,000点以上** あること

### 立直の効果

| 効果 | 説明 |
|------|------|
| 翻数 +1 | 「立直」で1翻追加 |
| 裏ドラ | 和了時に裏ドラが有効になる |
| 一発の可能性 | 宣言後、次の自分のツモ番までに和了すると「一発」で+1翻 |
| 供託 | 1,000点を場に供託する |

### 立直後の制約

- **手牌の入れ替え不可**: ツモった牌をそのまま切る（ツモ切り）か、ツモ和了のみ
- **副露不可**: ポン・チーは宣言できない
- **槓の制限**: 一般ルールでは「待ちが変わらない暗槓」のみ許可されるが、**本ゲームでは立直後の槓は全面不可**
- **フリテン**: ロンを見逃すと以降ツモ和了しかできない（リーチ後見逃しフリテン）

### ダブル立直（ダブルリーチ）

自分の最初の打牌で立直を宣言し、かつそれまでに誰も副露していない場合。**2翻**。

## 槓（カン）

同じ牌4枚を1つの面子として扱う宣言です。3種類あります。

### 暗槓（アンカン）

- **条件**: 手牌に同じ牌が4枚ある
- **門前**: 維持される（副露扱いにならない）
- **処理**: 宣言後、嶺上牌（リンシャンハイ）から1枚ツモ → ドラ表示牌が1枚追加

### 加槓（カカン）

- **条件**: すでにポンしている明刻に、手牌から同じ牌1枚を加える
- **門前**: すでにポンで崩れているため関係なし
- **処理**: 宣言後、嶺上牌から1枚ツモ → ドラ表示牌が1枚追加

### 大明槓（ダイミンカン）

- **条件**: 手牌に同じ牌が3枚あり、相手の捨て牌で4枚目が出た
- **門前**: 崩れる
- **処理**: 宣言後、嶺上牌から1枚ツモ → ドラ表示牌が1枚追加

### 槓に関する共通ルール

- 嶺上牌でツモ和了すると **嶺上開花**（1翻）
- 槓のたびにドラ表示牌が増える（最大4回）

### 搶槓（チャンカン）

相手が **加槓** を宣言した際、その牌が自分の和了牌であればロン和了（搶槓）を宣言できます。1翻の役として扱われます。

> ⚠️ **本ゲームでは搶槓は未実装です。**

## ドラ

ドラは手牌に含まれるだけで翻が加算されるボーナス牌です。ただし **ドラだけでは和了できません**（他に最低1つの役が必要）。

### ドラ表示牌と実際のドラ

ドラ表示牌（牌山の特定位置にある牌）の **次の牌** が実際のドラとなります。

#### 数牌のドラ対応

| 表示牌 | → ドラ |
|--------|--------|
| 一萬 | → 二萬 |
| … | … |
| 八萬 | → 九萬 |
| **九萬** | → **一萬**（9の次は1に循環） |

筒子・索子も同様です。

#### 字牌のドラ対応

| 表示牌 | → ドラ |
|--------|--------|
| 東 | → 南 |
| 南 | → 西 |
| 西 | → 北 |
| **北** | → **東** |
| 白 | → 發 |
| 發 | → 中 |
| **中** | → **白** |

### ドラの種類

| 種類 | 説明 | 翻 |
|------|------|----|
| 表ドラ | ドラ表示牌から決まるドラ | 1枚につき1翻 |
| 裏ドラ | 立直和了時のみ有効。ドラ表示牌の下にある牌が裏ドラ表示牌 | 1枚につき1翻 |
| 赤ドラ | 赤い牌（五萬・五筒×2・五索）。持っているだけで1翻 | 1枚につき1翻 |
| 槓ドラ | 槓のたびに追加されるドラ表示牌 | 1枚につき1翻 |
| 槓裏ドラ | 槓ドラに対応する裏ドラ。立直和了時のみ有効 | 1枚につき1翻 |

> ⚠️ **槓裏ドラについて**: 槓でドラ表示牌が追加された場合、対応する裏ドラ表示牌も増えるのが一般ルールです。**本ゲームでは槓裏ドラは未実装**（初期の裏ドラ1組のみ有効）です。

### 本ゲームの赤ドラ（オプション）

| 牌 | 赤ドラ枚数 |
|----|------------|
| 五萬 | 1枚 |
| 五筒 | 2枚 |
| 五索 | 1枚 |

## フリテン

フリテンとは、特定の条件下で **ロン和了ができなくなる** ルールです。ツモ和了は可能です。

### 3種類のフリテン

#### 1. 捨牌フリテン

自分の和了牌（待ち牌）が自分の河（捨て牌）にある場合、ロン和了できません。

```
例: テンパイで三萬待ち → 自分の河に三萬がある → ロン不可（ツモならOK）
```

#### 2. 同巡内フリテン（一時フリテン）

他プレイヤーの捨て牌でロンできたのに見逃した場合、自分の次のツモ番まではロンできません。

```
例: 相手が三萬を捨てた → ロンを見逃した → 次の自分のツモまでロン不可
```

#### 3. リーチ後見逃しフリテン

立直中にロンを見逃すと、以降その局で **永続的にロンできなくなります**（ツモ和了のみ可能）。

## 符計算

符（フ）は手牌の構成に応じて付く点数の基本単位です。

### 基本符（副底）

| 条件 | 符 |
|------|----|
| 全ての和了に共通 | 20符 |

### 和了方法による加算

| 条件 | 符 |
|------|----|
| 門前ロン | +10符 |
| ツモ | +2符 |

> **例外**: 平和ツモの場合は符加算なし（固定20符）

### 面子による加算

| 面子の種類 | 中張牌 (2～8) | 么九牌 (1,9,字牌) |
|-----------|--------------|-------------------|
| 明刻（ポンした刻子） | +2符 | +4符 |
| 暗刻（手牌の刻子） | +4符 | +8符 |
| 明槓（加槓・大明槓） | +8符 | +16符 |
| 暗槓 | +16符 | +32符 |

### 雀頭による加算

| 条件 | 符 |
|------|----|
| 三元牌（白・發・中）の雀頭 | +2符 |
| 場風牌の雀頭 | +2符 |
| 自風牌の雀頭 | +2符 |

> 場風と自風が同じ牌（例: 東場の東家）の場合、2符+2符=4符と加算されます。

### 待ちによる加算

| 待ちの種類 | 説明 | 符 |
|-----------|------|----|
| 辺張（ペンチャン）待ち | 1-2で3待ち、8-9で7待ち | +2符 |
| 嵌張（カンチャン）待ち | 例: 1-3で2待ち | +2符 |
| 単騎（タンキ）待ち | 雀頭の片方を待つ | +2符 |
| 両面（リャンメン）待ち | 例: 3-4で2と5待ち | +0符 |
| 双碰（シャンポン）待ち | 2つの対子でどちらかの刻子完成待ち | +0符 |

### 符の切り上げ

計算した符は **10の位に切り上げ** ます。

```
例: 基本20 + 門前ロン10 + 暗刻4 = 34 → 40符に切り上げ
```

### 特殊な符

| 条件 | 符 |
|------|----|
| 七対子 | 固定 **25符** |
| 平和ツモ | 固定 **20符** |
| 上記以外 | 最低 **30符** |

## 得点計算

### 基本の計算式

得点は **翻数** と **符** の組み合わせで決まります。

5翻以上は符に関係なく、翻数のみで固定の点数になります（満貫以上）。

### 本ゲームの得点表

本ゲームでは **親/子の区別なし** の統一得点表を使用しています。

#### 1～4翻（符による変動あり）

| 翻＼符 | 20符 | 25符 | 30符 | 40符 | 50符 | 60符 | 70符 |
|--------|------|------|------|------|------|------|------|
| **1翻** | 1,000 | — | 1,000 | 1,300 | 1,600 | 2,000 | 2,300 |
| **2翻** | 1,300 | 1,600 | 2,000 | 2,600 | 3,200 | 3,900 | 4,500 |
| **3翻** | 2,600 | 3,200 | 3,900 | 5,200 | 6,400 | 7,700 | — |
| **4翻** | 5,200 | 6,400 | 7,700 | 満貫 | — | — | — |

> 25符は七対子専用です。3翻70符以上、4翻40符以上は満貫扱いになります。

#### 5翻以上（固定点数）

| 翻数 | 名称 | 得点 |
|------|------|------|
| 5翻 | 満貫（マンガン） | 8,000 |
| 6～7翻 | 跳満（ハネマン） | 12,000 |
| 8～10翻 | 倍満（バイマン） | 16,000 |
| 11～12翻 | 三倍満（サンバイマン） | 24,000 |
| 13翻以上 | 役満（ヤクマン） | 32,000 |

### ロンとツモの支払い

| 和了方法 | 支払い |
|----------|--------|
| ロン | 振り込んだプレイヤーが全額支払い |
| ツモ | 相手が全額支払い（2人麻雀のため分割なし） |

## 本ゲーム固有のルール（2人麻雀）

### 4人麻雀との主な違い

| 項目 | 4人麻雀 | 本ゲーム（2人麻雀） |
|------|---------|---------------------|
| プレイヤー数 | 4人 | **2人** |
| 使用する牌 | 136枚 | **136枚**（標準セットと同じ） |
| 配牌 | 13枚 | **13枚** |
| チー | あり | **なし** |
| 席風 | 東・南・西・北 | **東・南のみ** |
| 局の構成 | 東1～4局、南1～4局 | **東1局・東2局・南1局・南2局** |
| 得点の親/子区別 | あり（親は1.5倍） | **なし**（統一テーブル） |
| ツモ時の支払い | 3人で分割 | **相手1人が全額** |

### 初期設定

| 項目 | 値 |
|------|----|
| 初期持ち点 | 25,000点（設定で変更可能） |
| 立直供託 | 1,000点 |

### 風と局の進行

- **東家（親）** と **南家（子）** の2席
- 局の進行: 東1局 → 東2局 → 南1局 → 南2局
- 親が和了 → 連荘（親続行）
- 子が和了 → 親交代
- 流局時 → 親がテンパイなら連荘、ノーテンなら親交代

### 本場（ホンバ）

一般的な麻雀では、連荘や流局のたびに **本場数** がカウントされます。本場数に応じて和了時の得点にボーナスが加算されます。

| 条件 | ボーナス |
|------|----------|
| ロン和了 | +300点 × 本場数 |
| ツモ和了（4人麻雀） | +100点 × 本場数（各プレイヤーから） |
| ツモ和了（2人麻雀） | +300点 × 本場数（相手から） |

> ⚠️ **本ゲームでは本場カウンターは未実装です。** 連荘は正しく処理されますが、本場数による得点ボーナスは加算されません。

### 王牌（ワンパイ）の構成

牌山の末尾から22枚が王牌として予約されます。

| 区分 | 枚数 | 用途 |
|------|------|------|
| 嶺上牌 | 3枚 | 槓の後に引く牌 |
| 嶺上牌予備 | 3枚 | 追加の嶺上牌 |
| ドラ表示牌候補 | 4枚 | 槓ドラ用（最大4回の槓に対応） |
| ドラ実牌候補 | 4枚 | — |
| 裏ドラ表示牌候補 | 4枚 | 裏ドラ用 |
| 裏ドラ実牌候補 | 4枚 | — |

### ツモ運システム（本ゲーム独自）

ツモの引き運をレベルで調整できるオプション機能です。

| レベル | 効果 |
|--------|------|
| 0 | なし（完全ランダム） |
| 1 | 軽い補正（30%の確率で有利な牌を引く） |
| 2 | 中程度の補正（50%） |
| 3 | 強い補正（70%） |

配牌にも運レベルが影響し、高いレベルでは最大10回再配牌して最良の手牌を選びます。

## CPU AI の特徴

### 打牌選択

- **シャンテン数計算**: 通常形・七対子・国士無双の3パターンで計算
- **受入枚数評価**: 各牌を切った場合の受入（テンパイに近づく牌）の数を比較
- **手牌評価**: スーツ集中（ホンイツ・チンイツ狙い）、タンヤオ、役牌の保持などを加味

### 鳴き判定

- テンパイに近づくポンのみ実施
- 役を壊すポンを回避（例: ホンイツ狙いの手で関係ないポンをしない）
- 高得点役の構成可能性を評価

### 防御

- 相手の立直を検知すると守備モードに移行
- **現物（ゲンブツ）**: 相手の河にある安全牌を優先
- **筋（スジ）**: 安全度の高い牌を判断
- **壁（カベ）**: 場に見えている枚数から安全度を推定

### 立直判断

- 手牌の状況、点数状況、場の状況を総合的に判断して宣言

### 自動動作

- ツモ和了・ロンの自動判定
- 槓の自動判定（暗槓・加槓）

## FAQ

**Q: ドラだけで和了できますか？**
A: いいえ。ドラは翻を加算するだけで、役としては扱われません。他に最低1つの役が必要です。

**Q: 親と子で得点は変わりますか？**
A: 本ゲームでは変わりません。2人麻雀用に統一された得点表を使用しています。

**Q: 暗槓すると門前は崩れますか？**
A: いいえ。暗槓は門前を維持します。立直中は槓できませんが、暗槓がある状態で立直を宣言することは可能です。

**Q: 立直後にカンはできますか？**
A: 本ゲームでは立直後の槓は全面不可です。一般ルールでは「待ちが変わらない暗槓」のみ許可されますが、本ゲームでは簡略化のため禁止しています。

**Q: 緑一色に發は必須ですか？**
A: 必須ではありません。索子 (sou) の2,3,4,6,8のみでも成立します。🔴 **注意**: 本ゲームの現在の実装では誤って筒子 (pin) で判定されています（バグ）。

**Q: 大車輪とは何ですか？**
A: 筒子の2,3,4,5,6,7,8をそれぞれ2枚ずつ集めた七対子形の役満です。ローカルルールの一種です。

**Q: 赤ドラはありますか？**
A: オプションで有効にできます。五萬×1枚、五筒×2枚、五索×1枚が赤ドラになります。

**Q: チーはできますか？**
A: 本ゲーム（2人麻雀）ではチーは不可です。

**Q: フリテンでもツモ和了はできますか？**
A: はい。フリテンはロン和了のみを制限します。ツモ和了は常に可能です。

**Q: 流局時のテンパイ料はありますか？**
A: オプション機能として実装されています（デフォルトは無効）。ルーム作成時に `notenPenalty` を有効にすると、テンパイ者が +1,500点 / ノーテン者が −1,500点 の授受が行われます。一般ルールでは 3,000点 が標準です。

**Q: 搶槓（チャンカン）はありますか？**
A: 本ゲームでは搶槓は未実装です。加槓に対するロン和了はできません。

**Q: 本場ボーナスはありますか？**
A: 本ゲームでは本場カウンター（積み棒）は未実装です。連荘は正しく処理されますが、本場数による得点ボーナスは加算されません。

**Q: 九種九牌で流局できますか？**
A: 本ゲームでは途中流局（九種九牌）は未実装です。

**Q: ダブル役満はありますか？**
A: 本ゲームではダブル役満は非対応です。役満は常に単一（32,000点）として扱われます。
