# CPU牌効率改善 - 実装ドキュメント

## 概要
CPUプレイヤーの捨て牌選択アルゴリズムを大幅に改善しました。従来の簡単なロジックから、麻雀の基本的な牌組学（taile efficiency）に基づいた高度なアルゴリズムに変更しました。

## 改善内容

### 1. タイル分類システム（Tile Classification）✅
牌を3つのカテゴリに分類し、それぞれ異なる価値を付与：

- **標準牌（Standard）**: 2-8の数字牌
  - 最も重要
  - 順子・刻子を形成しやすい
  - リャンメン形成に最適
  
- **老頭牌（Terminal）**: 1と9
  - 価値が低い（形成できるメルドが限定的）
  - 優先的に削除対象
  
- **字牌（Honor）**: 東南西北白發中
  - コンテキスト依存
  - 対子を作られたくない
  - 孤立した場合は優先削除

### 2. タイル孤立度評価（Tile Isolation Score）✅
周囲の牌との繋がりを評価：

```
孤立度の計算：
- 隣接牌がない + 同じ牌がない → 情報 1.5（完全孤立）
- 隣接牌がない + 同じ牌1枚 → 1.0（対子だが孤立）
- 隣接牌1-2枚 → 0.5（わずかに繋がっている）
- 隣接牌3枚以上 → 0（しっかり繋がっている）
```

孤立度が高い牌ほど削除スコアが高くなります。

### 3. 複合可能性評価（Combination Potential）✅
牌が参加できるメルドの数を計算：

- **刻子の可能性**: 同じ牌が複数ある
- **順子の可能性**: 隣接牌との組み合わせ
  - リャンメン形: n-1, n, n+1 → 最高値
  - カンチャン形: n, n+2 または n-2, n → 中程度
  - ペンチャン形: n, n+1 または n-1, n → 中程度

複合可能性が高い牌はマイナススコア（削除したくない）

### 4. リャンメン効率評価（Ryanmen Efficiency）✅
特に中央牌（4, 5, 6）の効率を重視：

```
リャンメン形の価値：
- 中央牌（4, 5, 6）： 80 + 隣接度 = 最高
- 周辺牌（2-3, 7-8）： 30-10 + 隣接度 = 中程度
- 隣接牌の数で追加ボーナス（最大60）
```

### 5. シャンテン改善度評価（Shanten Improvement）✅
従来のテンパイ判定を進化：

- テンパイの場合: 待ちの数で大きなボーナス
- テンパイでない場合: 捨てることで待ちの数が何変わるかを評価
  - 待ちが減る：ペナルティ
  - 待ちが増える：ボーナス
  - 待ちが消える：改善と見なす

### 6. 手牌整形度評価（Hand Shape Score）✅

改善されたポイント：

#### スーツ分布
- 1スーツ集中（7枚以上）: +100（ほぼメノコース確定）
- 1スーツ集中（6枚）: +60
- 1スーツ集中（5枚）: +30
- スーツ数が2: +80
- スーツ数が3: -30
- スーツ数が4以上: -80

#### 連続性（Sequence）
- 7以上連続: +80
- 5以上連続: +50
- 3以上連続: +20
- 2連続: +5

#### 中央牌集中度
- 4-6の牌が5枚以上: +40
- 4-6の牌が3-4枚: +15

#### 老頭牌比率
- 非終端牌が10枚以上: +50（効率的）
- 非終端牌が6枚以下: -40（非効率）

### 7. 危険度評価の改善（Danger Assessment）✅

相手がリーチを宣言している場合：

- **字牌**: +200（安全）
- **通った牌の周辺**: +150（相手が通したなら安全）
- **中央牌（4-6）**: -300（両面待ちの中心、危険）
- **周辺牌（2-3, 7-8）**: -150（組み合わせの可能性）
- **端牌（1, 9）**: -50（やや危険）

捨て牌の連続性から相手の待ちを推測し、リスクを調整します。

## スコアリングの重み付け

最終的なディスカード評価スコア：

```javascript
score = 0

// 1. テンパイ有利度（最優先、重み: 2x）
if (テンパイ) {
  score += 10000 + 待ちの数 * 100
} else {
  score += シャンテン改善度 * 2000
}

// 2. 危険度評価（重み: 1x）
score += 危険度スコア

// 3. タイル効率（重み: 2x）
score += (孤立度 + 複合性 + リャンメン) * 2.0

// 4. 手の整形度（重み: 1.5x）
score += 整形度スコア * 1.5
```

## 実装例

### 例1：初期手 4m5m6m 4p5p6p 3s4s5s 1z5z5z
```
最善の削除: 1z（東）
理由:
- 孤立した字牌（複合可能性: 0）
- 対子の相手がいない
- 他の牌は全てリャンメン形で価値が高い
```

### 例2：リーチ中の相手がいる場合
```
手牌: 2m3m5m 3p4p5p 2s3s8s 1z 5z 新牌
現局面で中央牌（5m）を保持：
- リスク: 両面待ちの中心 (-300)
- リャンメン価値: +80
- 複合性: -60
最終スコア: -280（保持を避ける傾向）
```

## パフォーマンス効果

### 期待される改善

1. **テンパイまでのスピード向上**
   - より効率的な牌削除により、シャンテン数が早く減少
   
2. **待ちの質向上**
   - リャンメン待ちを優先保持
   - 複合性の高い牌を温存

3. **和了率向上**
   - 無駄な牌削除の削減
   - リスク管理の向上

4. **失点削減**
   - リーチ相手への対応改善
   - 危険牌の回避
